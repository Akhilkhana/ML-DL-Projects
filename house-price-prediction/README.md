# 🏠 House Price Prediction

A machine learning web app that predicts California house prices using Ridge, Lasso, and Random Forest regression models — deployed with Flask.

## 📊 Dataset
- **Source:** California Housing Dataset (sklearn)
- **Rows:** 20,640  |  **Features:** 8
- **Target:** Median house value (in USD)

## 🧠 Models Used
| Model | R² Score |
|-------|----------|
| Ridge Regression | ~0.60 |
| Lasso Regression | ~0.60 |
| **Random Forest** ✅ | **~0.82** |

> Random Forest was selected as the final model for deployment.

## 🚀 How to Run

**1. Install dependencies**
```bash
pip install -r requirements.txt
```

**2. Run the Jupyter notebook** (trains and saves the model)
```bash
jupyter notebook house_price_prediction.ipynb
```
Run all cells — this saves `model/house_price_model.pkl`.

**3. Start the Flask app**
```bash
python app.py
```
Open [http://localhost:5000](http://localhost:5000) in your browser.
