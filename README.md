# ML-DL-Projects

End-to-end machine learning and NLP projects built with Python — covering data analysis, feature engineering, model training, evaluation, and web deployment.

## Projects

| Project | Description | Tech |
|---|---|---|
| [chatbot](./chatbot) | Rule-based conversational chatbot served via Flask | Flask · NLTK |
| [diabetes-prediction-svm](./diabetes-prediction-svm) | SVM-based diabetes classification (dataset included) | scikit-learn · pandas |
| [house-price-prediction](./house-price-prediction) | California house price prediction with Ridge, Lasso & Random Forest — Flask web app | scikit-learn · Flask |
| [multiple-language-translation](./multiple-language-translation) | Multi-language text translation with audio output via Streamlit | Streamlit · gTTS · mtranslate |
| [nlp_pipeline](./nlp_pipeline) | Modular NLP pipeline: preprocessing, POS tagging, NER, sentiment analysis | VADER · Python stdlib |
| [sentiment-analysis](./sentiment-analysis) | Twitter sentiment classifier (Positive / Negative / Neutral) — Flask web app | scikit-learn · TF-IDF · Flask |
| [sonar-rock-vs-mine-prediction](./sonar-rock-vs-mine-prediction) | Binary sonar signal classification (Rock vs Mine) | scikit-learn · pandas |
| [student-mark-predictor-deployment](./student-mark-predictor-deployment) | Predicts student exam scores from study hours — Flask web app with prediction logging | Flask · scikit-learn |

## Requirements

Each project has its own `requirements.txt`. Install per project:

```bash
cd <project-folder>
pip install -r requirements.txt
```

## Tech Stack

Python · scikit-learn · pandas · numpy · matplotlib · seaborn · Flask · Streamlit · NLTK · joblib
