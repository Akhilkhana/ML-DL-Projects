# 🐦 Twitter Sentiment Analysis

A machine learning web app that classifies tweets as **Positive**, **Negative**, or **Neutral** using NLP techniques — deployed with Flask.

## 📊 Dataset
- Twitter-style social media posts
- **90 samples** across 3 balanced classes (30 each)
- Classes: Positive 😊 · Negative 😠 · Neutral 😐

## 🧠 Models Used
| Model | Accuracy |
|-------|----------|
| Multinomial Naive Bayes | ~85–88% |
| **Random Forest** ✅ | **~88–92%** |

> Random Forest selected as final model for deployment.

## 🔧 NLP Pipeline
- **Text cleaning:** lowercase, remove URLs, mentions, hashtags, punctuation
- **Vectorization:** TF-IDF with unigrams + bigrams (5,000 features)
- **Classification:** 3-class sentiment prediction with confidence scores

## 🚀 How to Run

**1. Install dependencies**
```bash
pip install -r requirements.txt
```

**2. Run the Jupyter notebook** (trains and saves the model)
```bash
jupyter notebook sentiment_analysis.ipynb
```
Run all cells — this saves the model and vectorizer to `model/`.

**3. Start the Flask app**
```bash
python app.py
```
Open [http://localhost:5000](http://localhost:5000) in your browser.
